🎮 Tetra Script Hub - Week 1
This package bundles all Python scripts from Week 1 into a single, easy-to-use application. You do not need to have Python installed to run these programs.

🚀 Included Programs
Game – is a rock paper scisor game with the ai
Sidequest Generator – Creates random sidequests for new challenges and if you dont know what to do
Something – a tictactoe game a gainst another person you can choose who starts.
Sports Club Name Generator – Generates creative names for sports clubs.
To-Do List – A simple task manager to keep track of your goals. but it doesnt work :(
Wie bildet man einen Unfallbericht? – An interactive guide on how to write an accident report (in German) was created for my sister sice she is writting a class test about it .
🛠️ How to Download & Run
Download the menu.exe file from the Assets section below.
Double-click the menu.exe to open the program.
Choose a number from 1 to 6 in the terminal menu to launch the respective script.
After finishing a script, press the Enter key to return to the main menu.
